# Электр энергиясы — сабақ

Физика · 11 сынып · «Қазақстанда және әлемде электр энергиясын өндіру және қолдану» (CLIL · STEM · функционалдық сауаттылық).

Интерактивті сабақ: слайдтар, журнал және бағалау, топтар мен ұпайлар, кездейсоқ оқушы, таймер, глоссарий, Қазақстан картасы, гонка ойыны және энергия теңгерімінің конструкторы.

Бет — бір ғана `index.html` файлы. Ашу үшін файлды браузерде ашыңыз. Пернетақта: ← → — слайдтар, F — толық экран, R — кездейсоқ оқушы, P — қалам.
